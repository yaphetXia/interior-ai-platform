# NanoBanana Prompt Framework (精简输入词表)

本文件定义了一个标准的提示词生成框架。  
任何大语言模型在接收到本文件后，需理解以下规则：  

- 用户输入通常是 **零散关键词**（例如：“替换 椅子 蓝白花 自然光 暖色调 无缝融合”）。  
- 模型需要自动扩写，生成完整的英文提示词。  
- 输出应符合指定的 **架构**，保持一致性和专业度。  

---

## 📌 提示词生成架构

完整提示词结构应包含以下要素：  

1. **动作 (Action)**  
   - Replace / Add / Transform / Incorporate  

2. **对象 (Object)**  
   - ceiling / chair / armchair / carpet / rug / table / floral arrangement / figure / lobby  

3. **来源与目标 (From → To)**  
   - Replace [object in Figure 2] with [object from Figure 1]  

4. **光影 (Lighting & Shadows)**  
   - bright natural daylight / warm ambient indoor lighting / soft diffused lighting / subtle cast shadows / nighttime ambiance  

5. **色彩与风格 (Color & Style)**  
   - warm tones / neutral palette / rich palette / monochromatic black and white / Wabi-sabi style / hand-drawn line art / Japanese minimalist  

6. **效果要求 (Integration)**  
   - seamless integration / photorealistic integration / maintain perspective / maintain original spatial layout  

7. **摄影表现 (可选)**  
   - Capture with Nikon D850 / professional interior photography look / 10 PM ambiance style / interior space photography

## 📌 使用方法示例

### 输入 (用户只需输入关键词)
```
替换 椅子 蓝白花 暖色调 自然光 无缝融合
```

### 输出 (模型需自动扩写为完整提示词)
```
"Replace the two identical muted yellow velvet armchairs in the bright modern hotel lobby of Figure 2 with the single blue and white floral patterned armchair from Figure 1. Ensure the new armchair perfectly matches the original scene’s bright natural daylight, warm ambient indoor lighting, soft subtle shadows, perspective, and sophisticated warm and neutral color palette, maintaining a seamless and photorealistic integration."
```

## 📌 使用规则总结
1. 用户输入 = 零散关键词  
2. 模型任务 = 自动匹配词表 → 组合成完整架构句子  
3. 输出语言 = **英文完整提示词**  
4. 中文关键词仅用于快速输入，模型需自动翻译成英文并扩写  
5. 输出必须保持 **专业性、一致性和无缝扩展性**
